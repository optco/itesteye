Install in 5 steps

    Download the ZIP
    Click the button above and save iTestEye_Setup.zip.
    Unzip it
    Right-click the ZIP, choose Extract All, then Extract. Don't run the installer from inside the ZIP.
    Run as administrator
    Right-click iTestEye_Setup.bat and choose Run as administrator. On Windows 11, click Show more options first. Click Yes when Windows asks for permission.
    Open
    Edit
    Run as administrator
    Properties
    Wait for the installer
    If your PC doesn't have Python, the installer adds it. This can take a few minutes. It's finished when the window says All done.
    Open the app
    Double-click iTestEye Image Downloader on your Desktop, paste a page address, and click Download. Images are saved in Downloads\iTestEye Images.

If Windows shows a warning

Because the installer isn't digitally signed, Windows or your browser may ask you to confirm.

Browser: choose Keep when it says the file isn't commonly downloaded.

Windows protected your PC: click More info, then Run anyway.
