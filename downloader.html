Install in 5 steps

  1. Download the ZIPClick the button above and save iTestEye_Setup.zip.
  2. Unzip itRight-click the ZIP, choose Extract All, then Extract. Don't run the installer from inside the ZIP.
  3. Run as administratorRight-click iTestEye_Setup.bat and choose Run as administrator. On Windows 11, click Show more options first. Click Yes when Windows asks for permission.

  4. Wait for the installerIf your PC doesn't have Python, the installer adds it. This can take a few minutes. It's finished when the window says All done.
  5. Open the appDouble-click iTestEye Image Downloader on your Desktop, paste a page address, and click Download. Images are saved in Downloads\iTestEye Images.

If Windows shows a warning

Because the installer isn't digitally signed, Windows or your browser may ask you to confirm.

Browser: choose Keep when it says the file isn't commonly downloaded.

Windows protected your PC: click More info, then Run anyway.

Why a .bat installer and not an .exe?

Windows Smart App Control blocks unsigned .exe programs with no way to override it. A script installer isn't blocked.

What does the installer change on my PC?

It installs Python 3.12 only if you don't already have it, copies the app to C:\Program Files\iTestEye Image Downloader, and adds shortcuts to your Desktop and Start menu.

How do I uninstall it?

Delete the Desktop shortcut and the iTestEye Image Downloader folder in C:\Program Files.

Does it work on Mac or phones?

No. It's for Windows PCs only.
